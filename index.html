✨ Tutorial completo do Minha Lista

Role o conteúdo. Cada etapa aparece com uma transição quando entra na tela e a barra mostra seu progresso.

1️⃣ 🛒 Criando sua lista

Na aba Lista, digite o nome do produto, informe a categoria, quantidade e preço. Marque os itens comprados conforme avança no mercado. O total marcado aparece na barra inferior e o orçamento mostra quanto você já comprometeu.

2️⃣ ✍️ Digitação inteligente

Depois que um produto é cadastrado, comece a digitar o mesmo nome novamente. O catálogo mostra sugestões com categoria, último preço e média. Toque na sugestão para preencher os campos automaticamente.

3️⃣ 🧠 Lista Inteligente

Ao registrar compras no histórico, o sistema calcula padrões simples de recorrência. Quando um produto costuma voltar depois de determinado intervalo, ele pode aparecer como sugestão. Também pode sinalizar quando o último preço está acima da média registrada.

4️⃣ 🧾 Finalizando uma compra

Marque os produtos que realmente comprou e toque em Finalizar compra. O sistema cria um registro permanente com data, hora, itens, quantidades, preços e total. A lista atual continua disponível e o histórico fica separado.

5️⃣ 🔁 Repetindo uma compra

No Histórico, abra uma compra antiga. Você pode usar Repetir compra para levar aqueles produtos novamente para a lista atual, economizando digitação.

6️⃣ 📦 Catálogo de produtos

O catálogo guarda produtos conhecidos, categoria, quantidade de usos, último preço e média. Ele é a base das sugestões inteligentes e ajuda a evitar que você redigite o nome do produto toda vez.

7️⃣ ☁️ Minha Conta

Entre com Google para vincular seus dados ao seu usuário Firebase. Quando conectado, o sistema mostra nome, e-mail, foto e estado da sincronização. Seus dados continuam disponíveis localmente mesmo sem internet.

8️⃣ 🔄 Sincronização

Depois do login, o sistema compara os dados locais com os dados da nuvem usando a data de atualização. Se a nuvem tiver dados mais recentes, eles podem ser recuperados; se os dados locais forem mais novos, eles são enviados para sua conta.

9️⃣ 💾 Backup

Na área Segurança, use Fazer backup agora para gerar um arquivo JSON. Antes de restaurar outro backup, o sistema preserva uma cópia do estado atual. Também é possível exportar o histórico para CSV.

🔟 🚀 Atualizações

Quando uma nova versão for publicada, o sistema verifica o arquivo de versão e mostra a atualização disponível. Mais tarde mantém a versão atual. Atualizar agora instala a nova versão sem apagar os dados locais.

🛡️ Segurança

Os dados do Firestore são protegidos pelo UID da conta. Um usuário autenticado só pode acessar o próprio documento. Mesmo assim, mantenha backups periódicos como camada adicional de segurança.
